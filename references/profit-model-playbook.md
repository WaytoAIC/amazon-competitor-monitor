# 盈利模型雷达规则

## 核心框架

竞品监控不能只看前台运营指标。要用盈利模型拆解对手：

```text
Amazon profit model = traffic efficiency x conversion efficiency x supply-chain efficiency / capital occupation
```

这个公式是策略归因框架，不是精确财务公式。没有用户内部成本数据时，只能基于公开可观测代理指标推断。

## 四个维度

| 维度 | 解释什么问题 | 可观察代理指标 |
| --- | --- | --- |
| 流量效率 | 是否能以更低成本获得更精准流量 | 关键词覆盖、自然排名、广告入口、变体拆合、关联流量 |
| 转化效率 | 流量进店后是否更容易成交且客单价更高 | 主图/场景/文案、Review 星级、评分数、价格带、品牌溢价 |
| 供应链效率 | 是否具备更低边际成本和更快交付 | 材质聚焦、品类聚焦、变体复用、包装结构、上新相似度 |
| 资金实力 | 是否能承受库存、投放和周期压力 | 库存深度、断货频率、补货节奏、上新频率、低价持续时间 |

供应链效率和资金实力通常是代理推断，置信度默认不超过 `medium`，除非用户补充内部数据。

## 映射到竞品拆解

### 产品方案 -> 转化效率

分析重点：

- 产品到底卖给谁
- 主图和场景是否在筛选人群
- 文案是否在卖功能、场景、方案或价值感
- Review 是否支撑高客单价
- 包装、赠品、品牌表达是否形成溢价

结论应回答：

- 对手是否靠更强转化效率盈利
- 我方是否能通过图片、文案、场景或服务打它的弱点

### 变体策略 -> 流量效率

分析重点：

- 变体合并是否为了共享 Review 和权重
- 变体拆分是否为了覆盖不同关键词入口
- 是否存在引流款、利润款、形象款分工
- 广告和自然关键词是否形成流量分层

结论应回答：

- 对手是否通过变体结构降低流量获取成本
- 我方应该避开大词，还是用长尾词和关联流量切入

### 店铺布局 -> 资金效率

分析重点：

- 店铺是否存在引流款、利润款、形象款
- 低价款是清库存、挡竞品，还是长期流量入口
- 是否长期不断货，或反复断货
- 上新和补货节奏是否体现资金周转能力

结论应回答：

- 对手低价是否真的亏损，还是资金周转模型更强
- 我方是否应跟价、避战，还是只截取特定流量

### 类目策略 -> 供应链效率

分析重点：

- 是否聚焦材质、工艺、尺寸、配件或场景
- 多个产品是否可能共用模具、包装、供应商或物流方案
- 类目扩张是否围绕供应链复用，而不是随机铺货
- 是否通过包装或结构优化降低头程和仓储成本

结论应回答：

- 对手是否具备供应链复用壁垒
- 我方应该正面竞争，还是做差异化场景或单品极致

## 雷达评分

周报启用 `strategy-radar` 时，用 1-5 分评分：

| 分数 | 含义 |
| --- | --- |
| 1 | 明显弱势 |
| 2 | 偏弱 |
| 3 | 中性或证据不足 |
| 4 | 明显优势 |
| 5 | 强壁垒 |

每项必须包含：

- 评分
- 证据
- 代理指标
- 置信度

不要只给分数。

## 竞品画像类型

| 画像类型 | 模式 | 弱点 |
| --- | --- | --- |
| 流量型选手 | 流量效率高，广告或关键词覆盖强 | 广告成本上升时利润脆弱 |
| 品牌型选手 | 转化效率高，能卖溢价 | 扩品和供应链速度可能较慢 |
| 工厂型选手 | 供应链效率高，成本和交付强 | 品牌感、内容和服务可能弱 |
| 资金型选手 | 库存深、投放强、抗风险强 | 转化低或效率低时消耗大 |
| 均衡型选手 | 四维都较强 | 只能找局部弱点或错位竞争 |

## 策略地图

### 田忌赛马

适用场景：

- 对手是行业巨头或资金型选手

动作：

- 放弃大词流量
- 在长尾词和精准场景做到极致
- 用视觉、售后、组合方案打中尾部弱点

### 侧翼包抄

适用场景：

- 对手同体量，正面竞争成本高

动作：

- 产品侧翼：颜色、材质、套装、礼盒、场景差异化
- 流量侧翼：避开站内硬拼，尝试站外、内容或 SEO
- 人群侧翼：聚焦对手没有服务好的细分用户

### 吸血鬼策略

适用场景：

- 对手是流量型选手，流量强但转化弱

动作：

- Product Targeting 截对手 ASIN 页面
- 用更高评分、更强图片、更精准痛点文案承接流量
- 分析差评，把对手痛点写进我方 Listing

## 证据纪律

输出时必须分清：

- 数据事实
- 代理指标推断
- 长期假设
- 策略建议

证据不足时写“不足以确认”，不要强行归因。
